🌸 Iris Predictor AI – Multi-Model Flower Classification System
📌 Overview

Iris Predictor AI is a machine learning application designed to classify iris flower species using botanical measurements such as sepal and petal dimensions.

This project is an upgraded and more advanced version of a previous Iris classification system that originally used only a single machine learning model. In this improved version, multiple machine learning models were trained and integrated into one intelligent prediction platform to improve reliability, consistency, and overall prediction performance.

The application allows users to compare prediction outputs from different machine learning algorithms and identify the most reliable prediction result.

-- 🌟 Why the Ensemble Model?
The Ensemble Model is the most recommended model in the system because it combines the outputs and learning patterns of all the other trained models together.

Instead of relying on one algorithm alone, the Ensemble Model learns from:

Decision Tree predictions
Random Forest predictions
Gradient Boosting predictions

This combined learning approach improves:

Prediction stability
Accuracy
Reliability
Confidence in final outputs

-- 🧠 About Ensemble Learning
Ensemble Learning is a machine learning technique that combines multiple trained models together to improve prediction performance.

Instead of depending on a single algorithm, ensemble systems reduce prediction errors by leveraging the strengths of multiple models simultaneously.

This project demonstrates the practical application of ensemble learning in classification systems.
